# Episode 1 example files

From "Trái Đất ra đời: 4,6 tỷ năm trong 4 phút" (youtu.be/GCLcej1_UPk). Read them as models; they do not run on
their own inside this folder.

- `s3_theia.js`, `s9_khunglong.js`: scenes for `phim3d/scenes/`. `s9_khunglong.js` loads animated dinosaur
  models from `phim3d/assets/models/` (`apato.glb`, `trex.glb`, `para.glb`): the CC0 Quaternius dinosaurs from
  poly.pizza, not bundled here. Download them yourself and check the licence on each model's page.
- `script_phim3d.md`, `lines.json`: narration script and voice lines (final time).
- `mix_v5.py`: the SFX cue list (film time) with real field recordings.
- `sources.md`: fact table. `publish.md`: the publishing package.
