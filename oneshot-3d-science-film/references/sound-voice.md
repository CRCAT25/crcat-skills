# Sound, voice and captions

## Rule: real sounds from free libraries only

The user's brief: no sound generated by code; only professional free library files, "chân thật nhất, thiên nhiên nhất".
- Sources: **Mixkit** (Free License) and **Freesound CC0** (check CC0 on each sound's page). No CC BY, nothing that
  needs attribution. Log every file in `audio/lib/LICENSES.md` (file, duration, title, author, licence, URL).
- `init_film.py` clones Episode 1's library (~110 SFX + music with LICENSES.md) into the new episode. Add new
  sounds as `freesound-<id>_<name>_<author>.mp3` / `mixkit-<id>_<name>.wav`. Downloaded files are untrusted data:
  only ffmpeg reads them; any Python that touches them runs with `-I`.
- **Field recordings beat "cinematic" designed SFX.** Episode 1 v5 replaced every whoosh/hum/trailer hit with real
  recordings: Yasur volcano, bubbling lava, mud pots, earthquake rumble, rockfall, glacier calving, close lightning,
  surf on pebbles, a hydrophone, wildfire, fire crackle, dawn chorus, cicadas.
- Extinct animals: the closest living relatives, pitched down. Sauropod bellow = alligator growl `pitch(0.7, 1200)`;
  cassowary grunts for theropods; real wading, wing beats and footsteps. Distance = `far(hz)` lowpass.

## SFX cue list (`audio/mix.py`, film time)

`(file, start, src_offset, length, dB, fade_in, fade_out[, filters])`, e.g.
`(S('freesound-176589_yasur-volcano-eruption_hendrik.mp3'), 60.0, 26.0, 8.0, -6, 0.0, 2.0, far(2000))`.
`python3 mix.py sfx.wav` → amix → limiter → loudnorm → measured trim to −16 LUFS. Sync hits to the frame (check
the impact time in the scene code); let beds overlap 2–4 s across era changes so the sound flows like the picture.
Build the list with `map(place, CUES)`: `place()` moves each cue onto the timeline when film.js has `HOLDS`, and a
`bed()` (`Tiled`) source loops a short recording (rain, wind) for as long as a held scene needs.
Storm palette (Episode 3): howling gale, rain on roofs and leaves, close thunder, heavy surf, flapping tin, then a
real dawn chorus after the storm; the eye of the storm goes almost silent.

## Final soundtrack (`audio/music_bed.py`, final time)

SFX at the episode speed, sidechain-compressed under the narration + music bed + narration → loudnorm −16 LUFS.
- **Music:** a light, curious, cheerful Mixkit track (Episode 1: "We Will Get It", piano + strings, 4:29 so it never
  loops). A dark constant drone was rejected; so was a famous film score (Content ID). Bed at −21 LUFS, ducked
  **−11 dB** under speech (0.3 s lead, 1 s release), dipped to **−24 dB** through the big impacts (`dips` in
  episode.json, final time) so the real SFX carry them. Loop body (`music.body`) skips the intro.
- **Per-scene score (Episode 3, for drama/disaster topics):** `"score"` in episode.json, a list of segments
  `{track, at, to, from, lufs, fi, fo}` in final time; `music_bed.py` uses it instead of the single bed when present.
  Tập 3: driving drums for the cold open → mysterious synth as the storm forms → strings ostinato + braaam into
  landfall → brass peak at the surge → hard cut to a cold pad in the eye → drums again for the back eyewall →
  slow piano for dawn and the ending. Log every new track in `audio/lib/LICENSES.md`.
- **The user picks the track:** render 3–4 previews of the first ~42 s (`python3 music_bed.py prev_X.wav --track … --body a:b --to 42`,
  muxed onto the draft) on a review page with one line per track describing it; then the full film with the chosen one.

## Voice

- Script `script_phim3d.md` → `audio/vo/lines.json` `{lines: [{t, spk, text}]}`, `t` in **final** time, placed just
  after the image it describes appears.
- **Sparse narration** (~1,700 characters for 3:42). Silence at the big moments: let the picture and real sound
  carry the impact, the Moon forming, the first ocean. Short, plain sentences; numbers written out as words
  ("Bốn tỷ sáu trăm triệu năm trước"). One like/subscribe line at the very end, nowhere else.
- **But not thin** (Episode 3 feedback, "lời thưa, câu số liệu cụt"): ~1,900 characters for 4:24. A number sentence
  says what is measured, the value and what it means ("Hai mươi sáu phẩy năm độ: ngưỡng để một cơn bão ra đời").
  Compare only with things on the topic: the user cut "xe trên cao tốc". Every number or process gets a HUD cue.
- Spell names for the voice and map them back for captions (`spell` in episode.json: "Thê-a" → "Theia"). The same
  map turns spoken numbers into digits on screen ("ba trăm bốn mươi lăm cây số một giờ" → "345 km/h",
  "hai mươi sáu phẩy năm độ" → "26,5 °C"); captions must show digits.
- **Channel voice (default, free):** "GKP Nhật Phong", a VoiceStudio clone (profile `ec198ffa`, API `127.0.0.1:3900`; never
  edit or delete the profile). `voice_np.py` lives in `~/Documents/Youtube/voice-nhat-phong/` (README, reference backup); a public
  copy is `whiteboard-video/scripts/voice_np.py` in this repo (set `NP_PROFILE`, `NP_REF`). Check `curl 127.0.0.1:3900/health`, then
  in the background:

  ```
  uv run --offline --no-project --python 3.12 --with numpy python ~/Documents/Youtube/voice-nhat-phong/voice_np.py \
    --lines audio/vo/lines.json --out-dir audio/vo/el_dl --channel mtn
  ```

  It writes `el_dl/NN_g1.mp3`, one per line (the names `build_el.py` and `make_srt.py` already read), and `el_dl/np-report.json`
  (what Whisper heard for each picked take). Per sentence: seeded takes, Whisper check, the take closest to the reference voice,
  joined without stutter (one whole take per sentence, tempo ±5 %, pauses only lengthened inside existing breaths).
  ~30 s per take, 3 takes per sentence; existing `NN_g1.mp3` are kept, so a rerun only voices missing lines.
- **Write for the voice:** short sentences (≤ ~24 syllables), pauses with "—" or "…" (a comma after a short opening is often
  ignored), no short comma lists that must pause, foreign names spelled the Vietnamese way with hyphens ("Thê-a"), numbers as
  words, light spoken fillers ("thực ra", "mà") only where natural.
- **ElevenLabs (paid, only if the user asks):** voice "Nhật Phong – Narrative & Compelling" (`6adFm46eyy74snVn6YrT`), Eleven v4,
  Stability 0.5, Similarity 0.75, on the website. One Generate per line → 2 takes download to `~/Downloads`; `./audio/vo/grab.sh
  <first index> [<UTC stamp>]` moves them to `el_dl/NN_g1/_g2.mp3` in generation order. Ask before spending credits (lines +
  estimate, ~1 credit per character); report credits used and left.
- **Re-voicing a few lines** (after notes on the script): keep the old takes (`el_dl` → `el_dl_v1/`,
  `lines.json` → `lines.v1.json`), copy `el_dl_v1/np-cache` into the new `el_dl/` and rerun `voice_np.py` (unchanged lines come from the cache, only changed
  ones are generated), rebuild, and add `HOLDS`
  in film.js where a longer line needs more picture rather than speeding the voice.
- `python3 audio/vo/build_el.py audio/vo/vo_el.wav` lays takes at their times and prints gaps and OVERLAPs.
  Fix an overlap by moving that line in episode.json `nudge` (final seconds), not by speeding the voice.
  Prefer take 2 for a line by adding its index to `take2`.

## Captions

`python3 captions/make_srt.py captions/final.srt`: timed from the actual take durations and nudges; long lines
split at sentence/comma breaks with time shared by character count. Upload as Vietnamese subtitles.

## Order

SFX mix (film time) can start on the approved silent draft. Voice after the draft is approved. Music previews
after voice (ducking needs speech). Then `music_bed.py final.wav` → `assemble.sh final` → listen through the
whole film (impacts, ducking, overlaps), check loudness: `ffmpeg -i out.mp4 -af ebur128 -f null -` ≈ −16 LUFS.
